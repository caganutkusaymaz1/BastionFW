BastionFW

A defensive Linux security platform: tail security logs, detect SSH and web attacks, stage temporary firewall bans, and expose an operator dashboard and Prometheus metrics.

View source on main Changelog README

What it does

Log analysis

Tails auth and web logs with an inode-aware async tailer and a 1 MiB buffer cap.

Detection

SSH brute-force and web-attack rules, plus native Coraza/CRS audit ingestion with a confirmed-match ban loop.

Firewall enforcement

nftables / iptables / ufw / firewalld backends, IPv4-only by policy, with a panic purge switch.

WAF sidecar

Coraza + OWASP CRS in detect/block modes with bi-directional deny-list sync and a fail-open deadman switch.

Operations

Bearer/cookie dashboard auth, Prometheus metrics, a Grafana dashboard, and a liveness watchdog.

Supply chain

Hash-pinned Python lock, digest-pinned image, SBOM, and Trivy HIGH/CRITICAL gating in CI.

v3.2.1 — SSRF hostname-resolution fix

_validated_url() now resolves hostnames via socket.getaddrinfo() and rejects any URL whose host resolves to a private, loopback, link-local, reserved, or cloud-metadata range — closing the classic localhost / DNS-rebinding SSRF bypass. Resolution failures are rejected too. The waf.trusted_internal_hosts allowlist is still honoured first, so trusted internal service names need no DNS lookup.
